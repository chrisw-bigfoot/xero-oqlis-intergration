What is a Legal Entity?

A legal entity is a separate company or organization within your Xero account that has its own chart of accounts and data.

Each legal entity maintains independent financial records. You'll create a separate financial report for each entity.

Select the legal entity you want to create a financial report for.

Uploading Report Files
Tips for uploading:
  • Files must be in CSV, XLSX, or XLS format
  • All files are optional - upload only what you need
  • Files are processed together as a single financial report
  • Upload files directly from your Xero exports
  • Files are deleted after processing for security

What is the Report Period?

The Report Period is the month and year that will be used to identify this financial report.

When to use this:
  • Current Period: If you're uploading a report for the current month, the default is set automatically.
  • Back-Loading Data: If you're uploading historical data from previous months or years, select the appropriate month and year.
  • Future Planning: You can also upload projected or forecast data for future periods.

The report period is used in the report ID (e.g., February2026-abc123).
